# Review of experimental Paste

Review covered source, integration, settings, build, and test files. A follow-up
review found four additional defects, fixed and verified on 2026-09-09. The
published 0.1.1 release remains unchanged.

## Findings and fixes

| Area | Finding and resolution | Evidence |
| --- | --- | --- |
| Failure handling | Pasting the complete clipboard after an error could duplicate definitions. A failed structured paste now returns zero edits and an explicit cancellation notice. | Error-path integration tests; native cancellation cases. |
| Repeated pastes | Renamed incoming definitions were added again on later pastes. Matching prior numeric IDs and named suffixes are now reusable, including dependency graphs and cycles. | Eight sequences, five consecutive pastes each, in both metadata workers and both editor modes. |
| Feedback | Successful reuse was silent. Successful processing now reports added, reused, and renamed counts. | Integration assertions and notices observed in the running application. |
| Cache timing | A 1.5-second wait could expire before Obsidian's two-second automatic save. Paste now explicitly saves when needed, then waits for matching metadata. | Save, failure, timeout, recovery, and actual consecutive-paste checks. |
| Source fidelity | Body extraction could remove the next paragraph's indentation; CRLF and LF buffers have different offsets. Separator removal preserves indentation, and metadata is projected only across equivalent line endings. | Native fixtures and editor coordinate tests. |
| Markdown boundaries | Insertion into math, Wiki links, URLs, or HTML could report success without producing a native footnote reference. Unsafe contexts now cancel; complete replacements and normal link labels remain usable. | Native resulting-reference assertions and new context cases. |
| Blank lines and escapes | Indentation could turn the body into code; a preceding backslash could escape its first reference. Both cases now cancel without edits, while valid list and quote continuations pass. | Native boundary cases. |
| Lifecycle | A pending clipboard callback could query an editor after it was closed. View/lifecycle checks now precede cursor access. Concurrent pastes are rejected. | Disposed-editor and concurrent-invocation tests. |
| Undo | Adjacent typing could merge with a paste. A dedicated transaction event now receives CodeMirror's full history isolation annotation. | Real CodeMirror history tests; native editor Undo/Redo and selection restoration. |
| Deployment | The installed test-vault bundle predated the fixes. It was backed up, replaced by the new production bundle, and reloaded successfully. | Matching SHA-256 hashes and successful native application checks. |
| Joined syntax | Separately valid source and clipboard text could form a new fence, hide references, or create duplicate definitions. The completed local context is now checked before any edit is applied. | Fence, inline code/math, colon, old-reference, and definition-separation regressions. |
| Middle definitions | Removing a definition that interrupts a paragraph could merge surrounding body paragraphs. Required paragraph separation is now preserved, including CRLF. | LF/CRLF regression cases and actual resulting references. |
| Inline-footnote brackets | A right bracket inside inline code ended the protection range early and allowed literal reference text to be renamed. Bracket balancing now skips literal ranges. | Clipboard and target cases, including multiple backticks. |
| Dollar amounts | Any two dollar signs were treated as math. Delimiter whitespace, following digits, and paragraph boundaries are now respected. | Currency, invalid delimiters, soft line breaks, and blank-paragraph controls. |

The audit also covered Copy traversal and duplicate-ID ambiguity, source/cache
association, atomic span rewriting, target-ID immutability, block clustering and
tie breaking, all placement settings, settings load/save and toggling, clipboard
errors, event cleanup, external host modules, and bundled dependency licenses.
No additional confirmed defect in those areas remains open from this review.

## Validation

- **527/527 automated tests**, TypeScript checking, and production build passed.
- Official Obsidian **1.8.7** and **1.13.7** workers each passed **38 Copy**,
  **114 Paste**, and **8 sequences / 40 consecutive pastes**. Every accepted
  structured Paste also retained all existing native definitions and matched
  the reported number of added definitions.
- The installed **Obsidian 1.13.7** application passed **320 scenario checks**:

| Native editor mode | Paste scenarios, including Undo/Redo or cancellation | Five-paste sequences | Copy scenarios |
| --- | ---: | ---: | ---: |
| Source | 114 | 8 | 38 |
| Live Preview | 114 | 8 | 38 |

The native harness used Obsidian's official CLI to invoke the registered plugin
commands. It exercised the actual editor, system clipboard, metadata events,
notifications, and Undo/Redo; it did not substitute an editor or metadata mock.
Fixture setup waited for indexing and rendering before placing and verifying
the selection. Consecutive pastes ran without an extra indexing wait between
rounds. Clipboard verification allowed up to 250 ms for
readback without re-running Copy. The saved final report recorded `passed` for
all 320 scenarios. Test notes were isolated from the user's existing notes.

The production bundle is **119,890 bytes**, with SHA-256
`B535826BC59FD0C430217233ED7A8409FA84531FC3ADD04C1DAA31766408D184`.
The repository bundle and installed test-vault bundle match.

The user's current Paste settings and original editor tab were restored after
the application checks. Temporary CLI access was turned back off after testing.

## Limits

These checks establish the listed desktop behavior, not every possible Markdown
input or mobile platform. Android/iOS physical-device testing remains outstanding.
Obsidian exposes no historical source version for caches created before plugin
activation; startup cache checks retain that documented API limitation.

These findings and validation results apply to version 0.2.0. The previous
0.1.0 and 0.1.1 tags and release assets are preserved. See
[Verification](verification.md) and [Experimental Paste](experimental-paste.md)
for reproduction and behavior.
