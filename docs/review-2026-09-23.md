# Code review, 2026-09-23

Reviewed the Copy and experimental Paste paths, metadata association, Markdown
boundary checks, definition matching, settings and command lifecycle, build,
packaging, and existing native metadata fixtures. Changes are on the review
branch; this review does not change the released 0.2.1 version or assets.

## Findings resolved

| Area | Finding | Change |
| --- | --- | --- |
| Copy | A selection ending inside a referenced definition copied the partial definition and appended its complete copy, creating two markers with the same ID. | Preserve the selected text alone when a needed definition intersects only part of the selection. Updated the existing native-fixture case and added both directions of partial-selection coverage. |
| Copy | Multiple editor selections silently copied only the primary range. | Hide the menu item for multiple ranges and make the command explain why it did not copy. |
| Paste reuse | A regular expression with a capture group per nested reference could backtrack excessively on adjacent references. It also reconstructed reference positions from normalized text. | Compare the text segments between actual parsed and cached reference spans, with one pass per candidate definition. Added a many-adjacent-references regression. |
| Paste metadata | Checking every definition-like marker against every known definition and literal range made cache validation quadratic in definition-heavy notes. | Sort the covered spans and walk them alongside the markers. |
| Metadata refresh | A matching indexed snapshot could be projected twice for the same decision. | Reuse the first match. |

## Validation

- Clean install with `npm ci`.
- `npm test`: 534 tests passed in six files, including captured metadata from
  Obsidian 1.8.7 and 1.13.7, CodeMirror history, and plugin integration.
- `npm run lint`, `npm run build`, and `git diff --check`: passed.
- `npm audit --omit=dev --audit-level=moderate`: zero reported runtime
  dependency vulnerabilities.

The official Obsidian workers and a running application were unavailable in
this checkout, so this review did not repeat native worker or physical-device
checks. Existing stored metadata fixtures still exercise both supported worker
versions in the automated suite. Copy from an unobserved, stale startup cache
retains the public-API limitation described in [Verification](verification.md).
